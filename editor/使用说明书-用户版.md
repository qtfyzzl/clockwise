# ClockWise Canvas 主题编辑器 · 使用说明书（用户版）

> 适用版本：ClockCanvasDesigner.exe v1.0
> 适用设备：ClockWise（ESP32 + 64×64 RGB 点阵钟，HUB75E）
> 一句话：这是一款给点阵钟做「表盘主题」的桌面工具，画出来的东西，传到钟上就是一模一样的效果。

---

## 1. 这是什么、能干什么

你的点阵钟显示的画面叫「主题」，本质是一个 JSON 文件。以前要手写 JSON、算像素坐标、把图片压进 1KB 以内，非常麻烦。

这个编辑器把这些都变成了**可视化拖拽**：

- 在一个放大显示的 64×64 网格上，拖拽摆放文字、时间、方框、线条、图片
- **所见即所得**：编辑器直接解析固件里真正用的字体，你看到的就是钟上最终显示的（逐像素一致）
- 图片自动压缩到设备能接受的大小，不用你自己算
- 能做**动画**（会动的图案、会移动的小精灵）
- 一键上传到钟，重启即生效

---

## 2. 安装与启动

1. 拿到 `ClockCanvasDesigner.exe`（约 10 MB，单文件）
2. 双击运行即可，**无需安装、无需联网、无需装 Python**

> 首次双击如果 Windows 弹出「已保护你的电脑」，点「更多信息 → 仍要运行」即可（因为这是未签名的个人程序，属正常现象）。

## 3. 界面长什么样

打开后是**三栏布局**：

| 区域 | 内容 | 干什么用 |
|---|---|---|
| **左栏** | 主题属性 + 元素列表 + 「动画」标签页 | 管理画面里有哪些东西 |
| **中间** | 64×64 大画布 | 拖拽摆放、看效果 |
| **右栏** | 选中对象的属性 | 改颜色、位置、大小等 |

底部状态栏实时显示：
- **JSON 体积 / 48KB**：主题文件大小，别超
- **元素数量**
- **校验结果**：`✓ 校验通过`（绿）/ `! 提醒`（黄）/ `✕ 错误`（红）。点它可以看详细说明。

## 4. 快速上手：做一个简单表盘

### 第 1 步：从模板开始

菜单「**文件 → 从模板新建 → 极简（边框+分隔线）**」，会得到一个带边框 + 大字时间的现成表盘。

### 第 2 步：改时间

- 左栏元素列表里点「时间/日期」那一项
- 右栏把「内容」改成你想要的格式，例如：
  - `H:i` → `14:07`（24 小时）
  - `H:i:s` → `14:07:33`（带秒）
  - `m-d` → `10-28`（月-日）
- 点「水平居中 / 垂直居中」按钮，字会自动放到正中间

### 第 3 步：加装饰

- 左栏「＋ 添加」→ 选「空心矩形」或「直线」
- 在画布上拖动它，或右栏改坐标
- 颜色点色块按钮，弹出调色板选色

### 第 4 步：保存

`Ctrl+S` 存成 `.json` 文件。或直接跳到第 7 节上传到钟。

## 5. 元素类型速查

| 元素 | 用途 | 关键属性 |
|---|---|---|
| **时间/日期** | 显示动态时间 | 格式串、字体、位置 |
| **静态文字** | 显示固定文字 | 文字内容、字体、颜色 |
| **空心矩形** | 边框 | 颜色、位置、宽高 |
| **实心矩形** | 色块 | 同上 |
| **直线** | 分隔线 | 颜色、两端坐标 |
| **图片** | 图案 | 图片（自动压缩）、位置 |

**字体四种**（高度不同）：

| 字体名 | 高度 | 适合 |
|---|---|---|
| `big` | 14px | 大号时间 |
| `medium` | 9px | 中号文字 |
| `picopixel` | 5px | 小字、日期 |
| `square` | 11px | ⚠️ 只有数字有字形，别拿它写字母 |
| `default` | 8px | 默认 5×7 |

## 6. 放图片

点阵钟对图片限制很严：**单张图片解码后必须 ≤ 1024 字节，宽 ≤ 64px**。这基本意味着 64×64 的全彩照片塞不进去，只能放小图标。

编辑器帮你解决这个难题：

1. 左栏「＋ 添加 → 图片」
2. 点「选择图片…」选一张图
3. 弹窗里：
   - **裁剪**：拖出框选要保留的部分，支持 1:1 / 4:3 / 16:9 等比例
   - **最大宽/高**、**色数**（2/4/8/16/32）：决定最终体积
   - 左下角实时显示 `宽x高 · 色数 · 字节数`，**绿色=能放，红色=超限**
   - **「多方案选择」**：底部一排缩略图，每个标了尺寸和字节数，**点一个直接用**，不用自己调参数
   - **「自动压到 1024B 以内」**：一键找到最优组合

> 经验：图标类（图标、emoji、logo）缩到 16~32px、4~8 色，通常只有几百字节，轻松放得下。照片类基本放不下，建议改用几何图形表达。

## 7. 上传到钟

1. 确认钟已通电、和电脑在**同一个 WiFi** 下
2. 工具栏「设备 IP」填钟的 IP（默认 `192.168.137.99`，可能变，可在路由器后台查）
3. 点「**测试**」→ 弹出「设备在线」即通
4. 点「**上传**」→ 确认主题名 → 上传成功后会问你是否重启
5. 选「是」，钟会在约 2 秒后重启并显示新表盘

> ⚠️ 两个坑：
> - 钟**刚开机 10 秒内**不要上传（它启动时如果本地没主题会去联网拉，期间不响应上传）。
> - 上传完**必须重启**才生效（这是固件设计，改 NVS + 重启，不热切换）。

「读取」按钮可以把钟上现有的主题拉回来继续改。

## 8. 做动画（会动的画面）

切到左栏「**动画**」标签页：

- **精灵组**：一组 = 多帧图片（连环画）。`＋ 组` 建组，`＋ 帧` 加一帧图片。
- **loop 实例**：把某个精灵组放到画布上，并设置动画参数：
  - `帧延时`：每帧停多久（毫秒）
  - `循环周期`：播完一轮多久重来
  - `位移时长` + `目标 x/y`：让精灵从起点滑到目标点
  - `往返`：到位后滑回来
- 选中 loop 实例后，画布上会出现 **🟧 橙色方块（起点）** 和 **🟢 绿色圆圈（目标点）**，**直接拖这两个标记**就能定位，不用输数字。
- 勾选「**播放动画预览**」，画布实时播放，看到的就是钟上的效果。

想快速看效果：菜单「文件 → 从模板新建 → **弹跳球动画**」。

## 10. 常见问题

**Q：图片放进去，钟上却什么都不显示？**
A：99% 是图片超了 1024 字节。设备对超限图片是「静默不显示」，不报错。编辑器里左下角如果显示红色/「超出」，别点确定。

**Q：上传时报「连接失败」？**
A：检查三点：① 钟通着电；② 电脑和钟同一 WiFi；③ IP 填对了（`测试` 能通过就说明 IP 对）。

**Q：改了没生效？**
A：上传后要点「重启」；保存到本地 JSON 文件本身不会改钟上的画面。

**Q：画面字被裁掉一半？**
A：文字的 x/y 是「基线起点」，不是左上角，字会往上冒。用「水平居中/垂直居中」按钮，别手算。

## 11. 边界须知（重要）

- 主题 JSON 上限 **48KB**（底部状态栏会实时显示占比）
- 单张图片解码后 **≤1024 字节**、宽 **≤64px**、**必须是 PNG**（JPG 不行）
- 精灵组内各帧**尺寸要一致**，否则钟上会错位（校验器会提醒）
- 动画预览是「理想时钟」模拟，真机上电时刻不同会导致起始相位略有差异，但节奏一致
